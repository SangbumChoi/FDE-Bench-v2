ルール

ルールを一つでも破ると成果物は無効になります。ただし、そのルールの区分が実行時の会社方針で緩和でき、エージェントが例外手続きを経た場合は除きます。

  • 物理的 決して緩和されない
  • 契約上 方針が契約上の例外を認める場合にのみ緩和される
  • 業務慣行 方針の例外手続きを経れば緩和されうる
ルール区分ティア説明（{{…}} のパラメータはルールシードで抽選される）
approved_vendor契約上easy, medium, hard部品は、承認仕入先リストでその部品の承認状況が承認済の仕入先にのみ発注します。
moq物理的easy, medium, hardすべての発注明細（週・部品・仕入先の1件）は、仕入先の最小発注数量以上です。
budget_cap契約上easy, medium, hard各月の購買額（発注週の月曜日が属する月で判定）は、その月の予算内に収めます。
quality_hold物理的easy, medium, hard{{hold_supplier}} は品質保留中で、W1〜W{{hold_until}} に入荷予定の同社の品物は返品されます。
allocation_cap物理的hard割当対象の部品について、1か月に1社の仕入先へ出す発注は、その仕入先の月間割当上限の範囲内に収めます。

ケースの解説（README）

購買スペシャリスト — manufacturing/procurement_specialist

2機種の制御基板（B100 と、ディスプレイ付きの B200）を組み立てる受託製造業者が、エージェントに20数点の部品について8週間分の購買発注計画（W1 = 2026年11月23日の週から W8 まで）を依頼します。「生産を止めず、かつ使いすぎにならないように」というものです。成果物は orders.csv（order_week,component_id,supplier_id,quantity）です。計画は生産計画に対して W1–W10 でシミュレーションされます。舞台は一つの事実を除いて特定の国に依存しません。予算は現地通貨（KRW）建てで、1社の仕入先がドル建てで見積を出し、それを固定の計画レートで換算します。

設定はティアとルールシードの組です。ティアは今回どの顧客ルールが適用されるかを決め、ルールシードはそれらのパラメータ（計画レート、安全在庫、割合の上限、品質保留）を候補プールから抽選します。公開ルールシードは3つ（42、3、78）なので、公開の正解は9通りです。それ以外のルールシードはすべて、同じ候補からの非公開の抽選です。エージェントはどの設定でも同じ依頼と同じデータを見ます（検証器はプロンプトとワークスペースがバイト単位で同一であることを確認します）。変わるのは隠れた要件（シミュレーションの顧客はこれをもとに答えます）と評価器です。進め方の調整項目（仕様をすべて渡すか先に質問させるか、顧客のペルソナ、データのノイズ、イベント）は、すべてのケースと同様にその上に適用されます（cases/README.md を参照）。

データ（どの設定でも同じ）

components（部品マスタ.csv：部品24点と新しいフラッシュ C25、critical フラグ、標準原価）、production_plan（生産計画.csv：機種別の基板枚数、W1–W10）、bom（部品表.csv：valid_from_week / valid_to_week 付き。C04 は W1–W5、C25 は W6–W10）、inventory（現在庫.csv：抵抗は5,000個巻きのリール単位）、open_orders（未入荷発注.csv）、supplier_quotes.xlsx（仕入先見積.xlsx：currency、unit_price、moq、2段階の全数量割引、営業日単位の lead_time_days。suppliers シートもあり）、approved_vendors（承認仕入先リスト.csv）、budget（購買予算.csv：月ごとの上限）、delivery_history（納入実績.csv：過去の納入188件、納期回答日と入荷日）、allocations（供給割当.csv：S03/C01、S03/C03、S08/C06 の月ごとの上限）、そして supplier_price_email.txt（下記の価格通知）があります。依頼文が納入実績、供給割当の通知、予定されているフラッシュの変更、価格メールに触れているため、どのティアでもこれらが見えます。

仕入先の価格メール

合成の仕入先通知（supplier_price_email.txt、2026-11-20 付）は、W4 以降に出す発注について C01/S03 のすべての見積単価段階を20%引き上げることを承認しています。それより前の発注は見積どおりの価格のままです。さらに5%の値上げが承認待ちで、これは除外されます。発注週によって購買コストと月次予算の両方の価格が決まり、未入荷発注は影響を受けません。これは ReflectionAI の購買シナリオにある、承認済みの価格変更と承認待ちの価格変更の区別を取り入れたものです。

参照解とベースラインの数値（シード 20261123）

参照解は部品ごとの時間区分 MRP（time-phased MRP）です。展開した所要量から在庫と未入荷発注を差し引いて正味所要量を求め、まだ間に合う仕入先のうち最も安いところに、できるだけ遅く発注します。1回の発注で2週間分（または1週間分）をまかない、割引段階まで数量を切り上げたほうが合計が安ければ切り上げます（medium/hard）。次に重要部品について、割合の上限を満たすまで発注明細を丸ごと2社目の供給元に移します。残る在庫は最も遅い明細から削ります（トリム）。そのほうが部品のコストが下がるなら、その部品が最後の週まで目標を上回って持つ分だけ明細を減らすか、同じ週に最小発注数量の小さい仕入先に置き換えて、まだ足りない分だけを発注します。ある月が予算を超える場合は、まだ間に合う仕入先で発注明細を丸ごと翌月の最初の週に移します。後ろ倒しにした1ウォンあたりの追加コストが最も安い明細から移し、それぞれ新しい入荷週からその部品にまだ必要な数量に合わせて数量を決め直します（そのため hard で Express Parts Korea（S09）に後ろ倒しした切り替え対象の C04 は1,400個で、置き換えた S03 の最小発注数量4,100個ではありません）。間に合うように移せる明細がなければ明細を1つ遅らせて移し（部品はそれを待ちます）、12月に余裕があれば1月の超過分を W6 に前倒しし、何も移せなければ明細を1つ削ります（安全在庫不足か欠品待ちを受け入れます）。こうして、ルールシードが何を抽選しても参照解は有効になります。hard では、実績での平滑化した遅延率が5%を超えるすべての仕入先に1週の安全リードタイムを置き、供給割当を守ります。参照解は15の変種のうち、自身のコストの見方で有効かつ最も安い計画を採ります。変種は、2社目の手順の有無と2週または1週ロットを組み合わせた正味計算プランナーと、重要部品のすべての発注を割合の上限で2社目の供給元と分けるロット・フォー・ロットのプランナー（顧客のクォータの慣行で、2社目の供給元が高いときは明細を丸ごと移す方式より有利）のそれぞれについて、トリムを予算の手順の前後両方で行う、後だけで行う（先にトリムすると、予算の手順にはより高い後ろ倒ししか残らないことがある）、まったく行わない、のいずれかを組み合わせたものです。使うのはエージェントに見える情報だけです。遅延は実績から推定し、真の確率は決して使いません。

ベースライン（baseline_solution、正規化尺度で品質0）は、顧客がエンジニアなしで現在行っている方法、つまり ERP の素の MRP 実行と購買担当者の手直しです。すべての部品をロット・フォー・ロット（lot-for-lot）で発注します（各発注は在庫または安全在庫が最初に不足する週をまかない、最小発注数量以上）。間に合う承認済み仕入先のうち最も安いところへ、リードタイムが許す限り遅く、定価で、約束どおりの日付を前提に発注します（数量割引なし、納入実績は使わない）。重要部品はクォータ方式（quota arrangement）に従います。すべての発注を次に安い別の仕入先と分け、どちらも割合の上限を超えないようにします。予算を超えた月は参照解と同じように発注明細を丸ごと翌月に移し、1月の明細は W6 に前倒しします（12月に余裕がなければ参照解と同じように削ります）。

データ上の予算は11月115 M、12月475 M、1月85 M KRW です。予算は、すべてのティアについて候補プールの許容されるすべての組み合わせ（225通り）で、制約なしの計画をもとに調整しています。11月は、どの組み合わせであれ11月に使う額の最小値の95%を5 M 単位で切り捨てた値なので、ルールシードが抽選しうるすべての組み合わせで効きます。12月は、ある組み合わせが12月に使う額と11月に上限を超えて使う額の合計の最大値に対して5%の余裕があり、1月は、どの組み合わせであれ1月に使う額の最大値に対して5%の余裕があります。供給割当は月あたり C01 6,500、C03 9,000、C06 3,500 です（調整用の値 1,380 / 1 / 80% / S07（W3 まで）、つまり以前のルールセット A での、制約なしの hard の計画のピーク月の60%）。

このワールドでは225通りの組み合わせすべてで、参照解とベースラインは有効で、ベースラインのほうが悪く（比は easy で1.045–1.136、medium で1.032–1.122、hard で1.156–1.410）、制約なしの計画は11月の予算を超えます。参照解は11月の明細を1つ遅らせて移さなければならないことがあり（部品は1週待ちます）、いくつかの hard の組み合わせでは12月も効きます。ワールドシード 1、2、3 でも、それぞれ225通りすべてで同じことが成り立ちます。参照解とベースラインは有効で、ベースラインは少なくとも 3.5% / 2.5% / 12.8%（ワールド 1、easy / medium / hard）、1.2% / 1.0% / 14.9%（ワールド 2）、1.1% / 1.2% / 16.9%（ワールド 3）悪くなります。差が最も小さいのは Kowon Passive（S07）が W3 まで保留で安全在庫が0.5週の組み合わせで、そこでは参照解の最良の計画は、予算の手順の後にトリムするクォータ方式のプランナーです（REVIEW.md の「ルールシード」を参照）。検証はワールドシード 1–3 での公開ルールシードも対象にしています。

期待値の計算方法（hard）

遅延は最大2週なので、w週末の部品の正味在庫ポジションは、w−1週と w週に約束された納入を除けば確定しています。採点器は週ごとにそれらの納入の同時結果をすべて列挙し（その部品を見積もる仕入先ごとに最大2件なので、状態は最大2^8通り）、在庫保管、欠品待ち、安全在庫不足、廃棄の期待値を求めます。結果は厳密かつ決定的で、サンプリングは一切行いません。
