# 世帯生活支援金の支給決定

## 背景

世帯生活支援金の申請が300件ほど滞っています。どの世帯が対象になるか、毎月いくら支給するかを決めていただけますか。申請一覧、世帯員、資産申告、昨年度の支給額表、それから市民向けにお配りしているご案内を添付します。ご案内は市民向けのため、あえて数字を載せていません。正確な基準は以下のとおりです。私どもが重視しているのは、すべての世帯に今年度の基準で本来受け取るべき額を正確に支給すること、そして何よりも、対象でない世帯を承認したり、対象の世帯を不承認にしたりしないことです。不承認とする場合は、その理由も正確でなければなりません。

## 成果物

CSVファイル1つ、`determinations.csv` です。ヘッダーはASCIIで `household_id,eligible,monthly_amount,reason_code`、`申請一覧.csv` の申請1件につき1行です。

- `household_id` はデータの世帯番号のまま（例: H001）;
- `eligible` = `yes` または `no`;
- `monthly_amount` = 今年度の月額支給額（金額は当市の支給単位、対象外の場合は 0）;
- `reason_code` = `APPROVED`（新規承認）、`RENEWAL`（更新承認）、`DENY_RESIDENCY`、`DENY_ASSETS`、`DENY_INCOME` のいずれかです。`APPROVED` と `RENEWAL` は `eligible = yes` のときだけ、`DENY_` で始まるコードは `eligible = no` のときだけ使います。理由が複数ある場合は、居住、資産、収入の順で最初のものを記入してください。

## データについて

- **世帯人数**: `世帯員.csv` で `申請住所に居住` = はい の世帯員だけを数えます。別の場所に住んでいる世帯員（他の市で就学中の子、海外で働いている配偶者など）は世帯人数に含めず、その方の収入や障害の有無も一切考慮しません。
- **日付**: `申請一覧.csv` の `申請日` と `市内居住開始日` は「2025年3月5日」の形式です。
- **居住要件**: 申請日の時点で市内に6か月以上住んでいる必要があります。つまり `市内居住開始日` が `申請日` の6か月前の同じ日付以前でなければなりません（2026年9月14日の申請 → 2026年3月14日以前から居住）。法定の要件です。満たさない場合は対象外、`DENY_RESIDENCY` です。
- **資産**（`資産申告.csv`）: 申告された評価額をすべて合計しますが、お住まいの住宅（`居住用不動産`）と自動車1台は除きます（自動車が複数台ある場合は最も評価額の高い1台のみ除外し、残りは含めます）。この合計が、単身世帯で6,000、申請住所に住む世帯員が1人増えるごとに3,000を加えた額を超える場合は対象外、`DENY_ASSETS` です。
- **今年度の金額**: `2025年度支給額表.csv` は昨年度の表です。今年度の基準生活額と住居費上限は、昨年度の値を3.2%引き上げ、それぞれ10の倍数に切り捨てたものです（単身: 640 → 660、380 → 390）。新しい表はまだ公表前のため、データには入っていません。
- **必要額**: 世帯人数に応じた基準生活額 + 月額家賃（その人数の住居費上限まで。家賃のない持ち家世帯は0）+ 申請住所に住む `障害` = はい の世帯員1人につき120。
- **認定収入**（申請住所に住む世帯員のみ、すべて月額）: 就労収入は1人ごとに最初の150を差し引き、残りの30%も差し引きます。つまり1人ごとに（就労収入 − 150）の70%を収入として数えます。年金、失業給付、`養育費`、その他収入は全額を数えます（養育費は収入ではないと思われている市民の方もいますが、世帯の収入に含めます）。
- **支給額**: 必要額 − 認定収入を1未満切り捨てした額で、世帯人数ごとの予算法上の上限を超えることはできません: 1人 1,050、2人 1,450、3人 1,800、4人 2,100、5人 2,350、6人以上 2,550。結果が0以下の場合は対象外、`DENY_INCOME` です。
- **更新**（`申請種別` = 更新、`前年度月額支給額` あり）: 処理を滞らせないため、更新申請は再審査せず昨年度の月額のまま承認するのが当課の運用です（理由 `RENEWAL`）。更新世帯はすべて居住要件と資産要件をすでに満たしています。

## 評価方法

**必須条件**（ひとつでも守られていなければ、結果全体が無効となります）:

- 居住6か月未満の世帯を承認しないこと。
- 資産基準を超える世帯を承認しないこと。
- 月額が世帯人数ごとの上限を超えないこと。
- すべての行に、決定と整合する有効な理由コードがあること（承認は新規申請なら `APPROVED`、更新申請なら `RENEWAL`）。
- 更新申請は昨年度の月額とまったく同じ額で承認すること。

**品質**: 全世帯について、実際の支給額（対象外なら0）と今年度の基準で本来受け取るべき額との差の絶対値を合計し、対象かどうかの判断を誤った世帯1件につき400を加え、対象外と正しく判断したものの、最初に満たさない要件（居住、資産、収入の順）とは異なる理由コードを付けた世帯1件につき100を加えます。低いほど良い結果です。
