What the agent is asked

The client's request, the only text the agent gets up front. It is the same in every setting.

中文

管理层发来了一批问题，能麻烦您根据数据库导出的数据帮忙回答一下吗？数据表、简单的数据字典和问题清单都在附件里，每个问题给一个数字就行。

English

Our managers sent these questions. Can you answer them from the database export? The tables, a short data dictionary and the list of questions are attached — please send back one number per question.

한국어

경영진이 질문을 몇 가지 보내왔습니다. 데이터베이스 추출본으로 답을 내 주실 수 있을까요? 테이블, 간단한 데이터 사전, 질문 목록을 첨부합니다. 질문마다 숫자 하나씩 주시면 됩니다.

日本語

経営陣から質問がいくつか届きました。データベースのエクスポートから回答していただけますでしょうか。テーブル一式、簡単なデータ辞書、質問一覧を添付しています。質問ごとに数値をひとつずつお返しください。

Español

Nuestros directivos nos han enviado estas preguntas. ¿Podría responderlas a partir de la exportación de la base de datos? Le adjuntamos las tablas, un pequeño diccionario de datos y la lista de preguntas; con un número por pregunta nos basta.

Deliverable spec (shown to the extractor that reshapes the agent's files, not to the agent)

answers.json = {"Q01": <number>, "Q02": <number>, ..., "Q12": <number>}
One JSON number per question id from the questions file (Q01..Q12). Money in KRW,
percentages in percent (e.g. 4.25 for 4.25%), customer ids as the numeric customer_id.

Settings

This case has no settings: one fixed problem at every difficulty.

Rules

Breaking any rule makes the deliverable invalid, unless the rule's class may bend under the run's company policy and the agent went through the exception process.

  • physical never bends
  • contractual bends only if the policy allows contractual exceptions
  • business_policy may bend through the policy's exception process
RuleClassTiersDescription (parameters in {{…}} come from the rule set)
answer_formatphysical–Every question Q01..Q12 is answered with a single JSON number.
exclude_test_accountscontractual–Test accounts (account_type = test in accounts_meta) are excluded from every figure; an answer that matches only the test-inclusive figure breaches the finance policy.
report_roundingbusiness_policy–Every money figure (Q01, Q02, Q06, Q07, Q09) is reported rounded to the nearest thousand KRW.

Hidden requirements

What the simulated client knows and answers from. The agent only learns it by asking (in the full_spec engagement it is handed over).

Clarification targets

The facts a good engineer should ask the client for; Ask-F1 is scored against them. {{param}} is filled from the rule set.
