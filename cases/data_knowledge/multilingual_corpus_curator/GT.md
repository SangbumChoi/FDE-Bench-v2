# Ground truth: data_knowledge/multilingual_corpus_curator

The ground truth (GT) of a setting in five parts, with the reference as supporting evidence. Generated by `gt_report.py` from `dataset/audit.json` (`fdebench2 audit-case`, public world seed 20261027): 45 settings, easy 15, medium 15, hard 15 (each tier's public panel plus admissible parameter combinations). Damage is 1 − credit, credit = 0 for an invalid program, else the quality score clipped to [0, 1]; a target bites in a setting when misreading it alone loses at least 0.10 of the credit (for a drawn parameter: its least harmful wrong candidate). The program runs once per setting on the hidden drive (100 books, 119 files; 30 / 66 / 100 scored in easy / medium / hard).

- `encodings`: a data fact the sample shows (files that are not UTF-8), not a client fact (REVIEW.md F7). 7 hidden book(s); damage at most 0.122 in medium, 0.077 in hard (below 0.10 in hard, a tier where it would be in force).
- `year_notations`: a data fact the sample shows (era, Minguo, Dangi, Chinese-numeral and Roman years; F7). 6 hidden book(s); damage at most 0.105 in medium, 0.066 in hard (below 0.10 in hard, a tier where it would be in force).
- `duplicates`: a data fact the sample shows, and one book = one file is in the program interface (F7). 6 hidden book(s); damage at most 0.105 in medium, 0.066 in hard (below 0.10 in hard, a tier where it would be in force).
- `containers`: a data fact the sample shows (zip archives, catalog CSVs, scans, junk; F7). 14 hidden book(s); damage at most 0.153 in hard.
- `author_variants`: the official pair is the one the drive itself gives (the author's other books); it concerns few books. 5 hidden book(s); damage at most 0.087 in medium, 0.055 in hard (below 0.10 in hard, a tier where it would be in force).
- `exceptions`: split into `no_description`, `conflict` and `generic_titles`; the rest (a field taken from another file of the book, a meaningful file name as the title, a year from a `©` line) is the natural reading of the data and concerns 2-3 books each. 10 hidden book(s); damage at most 0.109 in hard.

## 2. Validity checks (hard gates)

A program that breaks any of these on the hidden drive is invalid and earns no credit. A program that writes no `manifest.csv` (or crashes before it) is fatal. The rules are checked on everything the program writes, also for books the tier does not score.

| rule | class | tiers | why it is a hard gate |
|---|---|---|---|
| `utf8_output` | physical | easy, medium, hard | the catalogue system reads the library and the manifest as UTF-8; a file in another encoding shows as mojibake or is rejected on import |
| `safe_names` | physical | easy, medium, hard | the library is copied to Windows and macOS shares and archived; a name a file system cannot hold breaks the copy |
| `one_file_per_book` | contractual | easy, medium, hard | the catalogue holds one record per book; a second file for the same book is a duplicate entry somebody has to find and delete |
| `review_reason` | contractual | easy, medium, hard | the review team works the queue by reason code; a free-text reason cannot be routed |
| `manifest_rows` | contractual | easy, medium, hard | the manifest is how the team finds what went where: a library file it does not list, a row pointing at no file, a placed row that names no file of the drive (nothing to trace the book back to) or a file listed twice makes the index wrong (mandatory output) |
| `review_copies` | contractual | easy, medium, hard | the review team looks at the material, not at a manifest row: a book sent to review without its files cannot be reviewed (mandatory output) |
| `no_fabrication` | contractual | hard | a made-up or placeholder blurb would be published as the book's description; the client said nothing may be invented |
| `no_guessing` | contractual | hard | a book filed under a guessed year or under a generic file name as its title is a wrong catalogue record; the request says anything that cannot be filed is set aside, not guessed |
| `missing_author_review` | business_policy | hard (when no_author in ['review']) | the catalogue does not shelve anonymous books (the client's cataloguing policy; an approved exception can bend it, scored with the rule switched off and a penalty) |
| `missing_author_shelved` | business_policy | hard (when no_author in ['Unknown', 'Anonymous']) | under a shelving policy the catalogue team agreed on one placeholder name for every author-less book; another name, or the review queue, breaks that agreement |

**Mandatory outputs.** The library is scored; the manifest and the review area are enforced directly (`manifest_rows`, `review_copies`), so a program cannot drop them, or keep the manifest's paths and leave its source column empty or filled with anything but files of the drive, and only lose a fifth of the credit. | shortcut | what it does | closed | best quality where valid |

| `placeholder_text` | File every book at its right path with a placeholder instead of its description | 45/45 | 0.080 |

| `no_manifest` | Write the library and the review area but leave manifest.csv with its header only | 45/45 | – |
| `no_review_copies` | Send books to review without copying their files under _review/ | 45/45 | – |

## 3. Objective (higher is better)

100 × the mean credit per scored book (the tier's books of the hidden drive), minus penalties:

- **Filed exactly**: 1 for the book's description at exactly the path the client's rules give. The catalogue team compares the library with its own catalogue path by path.
- **Misfiled**: 0.4 for the right description at any other path, whatever is wrong in it (layout, year, script, co-authors, separator, length). The description work is not lost, but somebody has to find the file and move it by hand: a wrong year is as lost on a shelf as a wrong author. (The first version gave 0.4 plus 0.2 per right component, so one misread rule cost a book only 0.2 and most rules could not matter; see REVIEW.md, Ground truth audit.)
- **Wrong text**: 0.2 for the right path holding anything other than the description (a heading, a title page, a placeholder).
- **Review**: 1 for a book that belongs in review when every manifest row naming its files says `review` with its reason code, 0.4 for another agreed code, 0 for rows that disagree or a library file as well; a book with no author under the review policy earns 0.7 in review (it is not on the shelf yet; shelving it is the bend, see `missing_author_review`).
- **Manifest row**: a missing or wrong row for the book costs 20% of its credit (the row must be the only one naming the book's files, name all of them, and say placed with its path or review with the files copied).
- **Stray files** (medium, hard): 0.5 per library file that is no book.

**Uncertainty.** The program is written on the sample and run once, unseen, on the full drive: the hidden drive has other books, other archive, catalog and numbered file names, a Shōwa-era year and zip members one folder deeper than the sample shows. What the program cannot settle from the files (a missing title or year, conflicting years, no description, no author) is not guessed: it goes to the review queue, where the team pays for it with its own time (the review credit), never as a wrong catalogue record (the rules).

## 4. Reference and bounds

- **Reference** (`reference/organize.py` with the setting's `config.json`): reads every format (JSON, ONIX, EPUB, DOCX, PDF, HTML, Markdown, text, catalog rows, zip members), decodes legacy encodings by the corpus's own character statistics, converts every year notation (eras, Minguo, Dangi, Chinese numerals, Roman numerals, `©` lines), groups copies by normalized title, takes each field by rank from any file of the book, maps every author to the official pair the drive gives for that person, detects same-rank year conflicts, and applies the setting's library rules and no-author policy. It files every hidden book exactly as `expected_output` does.
- **Baseline** (quality 0, `reference/baseline.py`): the client's own script, which shelves only books with a complete UTF-8 JSON record (title, author, plain four-digit year, description) under the catalogue rules, leaves a JSON record whose ISBN also has an ONIX export for the team (it cannot tell which is right) and leaves every other file alone.
- **Best known** (`best_known_solution`): the reference itself.
- **Bound** (`objective_bound`): a proven upper bound on a valid program's objective: every scored book earns at most 1, a book with no author under the review policy at most 0.7 (shelving it breaks `missing_author_review`), and penalties only subtract. `expected_output` reaches it, and so does the reference: the gap is 0 in every measured setting.
- **quality_cap** = 1.0: the best-known quality is 1.000 in every measured setting (median 1.000, range 1.000–1.000), so a program as good as the reference earns full credit and nothing scores above it.

## 5. Diagnostic cases

`score()` reports `enforced[target]` and a line of evidence for every target in force, for valid and invalid programs alike, from the same run of the program on the hidden drive as the score (the program is run once). The diagnostic inputs are the hidden books where only that fact decides the output. For a drawn library rule the program's own path of each such book is read back under every layout, year basis, script, co-author rule, separator and cut (`_path_readings`): the book counts for the fact when the client's value is among the readings that reproduce the path and not every candidate of the tier is, and against it when the client's value is not among them; a path that does not even have the client's layout's shape (e.g. `library/<title>.txt`) counts against `layout`. `content` counts a file at a book's path against the fact when it holds the description and more (a card, a title page) or no description at all (a placeholder); `missing_author` counts an author-less book that is neither shelved nor in review (left out, or listed as skipped) against it. For the other facts the inputs are the books (or review rows) the fact is about. `enforced` is True when no input counts against the fact and at least one counts for it. The audit checks that the reference is enforced everywhere and that every ablation that bites is not.

| target | diagnostic inputs (hidden drive) | result | settings where it fails |

| `layout` | every placed book (the order of year, title and author in its path) | separates | – |
| `year_basis` | placed books whose first publication and this edition differ | separates | – |
