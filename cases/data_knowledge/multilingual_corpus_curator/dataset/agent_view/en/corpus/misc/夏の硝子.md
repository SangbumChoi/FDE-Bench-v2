# 夏の硝子

*Natsu no Garasu*

伊藤美咲（Ito Misaki） 著

初版 1986年 / 新版 1998年

## 内容紹介

物語は書店がひとつしかない島から始まる。見知らぬ客が同じ本を買い占める――その理由を覚えているのは口をきかなくなった二人の姉妹だけだ。

ひと冬の出来事として、口をきかなくなった二人の姉妹と、町を離れようとしない人々を描く。
