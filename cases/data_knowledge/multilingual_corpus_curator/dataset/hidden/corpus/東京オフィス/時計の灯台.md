# 時計の灯台

*Tokei no Todai*

田中大翔（Tanaka Hiroto） 著

初版 平成9年 / 新版 令和元年

## 内容紹介

夜勤の図書館司書は長いあいだ書店がひとつしかない島を避けてきた。だが灯台の灯りが初めて消えると、すべてがよみがえる。

過去と現在を行き来する十七の短い章で、ささやかな優しさを問いかける。
