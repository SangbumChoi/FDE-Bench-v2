# 書類選考スペシャリスト — `people_hr/resume_screening_specialist`

シンガポールで成長中の決済会社が、3つの募集職種（R1 バックエンドエンジニア、R2 データアナリスト、R3 セキュリティ
アナリスト）に250件の応募を受け、エージェントに「面接に呼ぶべき候補者を絞り込んで、ショートリストを作って」ほしいと
依頼します。依頼には求人票、採用システムから出力した応募者データ、そして以前に同じ職種で採用した360名のデータが添付
されています。有効性と品質を決めるもの（職種ごとに8名、必須要件、どの職歴を関連経験として数えるか、期限切れの資格、
就労資格、1人1職種、アドバースインパクトのチェック、過去の評価点に含まれる管理職の偏り、社員紹介の慣行）はすべて
隠れた要件の中にあり、質問しなければわかりません。成果物は `shortlist.csv`（`role_id,candidate_id,rank`、職種ごとに
8行）です。

このケースには設定がありません。どの難易度でも同じ問題で採点されます。進め方の調整項目（完全な仕様を渡すか先に質問
させるか、顧客のペルソナ、データのノイズ、イベント）は、他のすべてのケースと同様にその上に適用されます
（[cases/README.md](../../README.md) を参照）。

## データ

| ファイル (en) | 内容 |
|---|---|
| `candidates.csv` | 応募者250名：`applied_roles`（R1〜R3 のうち1つまたは2つ）、`application_date`、`location`、`work_authorization`（国民、永住者、就労ビザ保有、ビザスポンサー要）、`highest_education`、`graduation_year`、`total_years_experience`（キャリア全体の合計で、罠）、`skills`（タグ）、`languages`、`referral`、そして保護属性の `gender`、`age_band`、`nationality` |
| `work_history.csv` | 職歴1件につき1行：`job_family` と開始・終了月（`present` = 現在も在職中） |
| `certifications.csv` | 資格1件につき1行で、`issued_on` と `expires_on` を含む |
| `past_hires.csv` | 2021〜2025年の採用者360名：入社時の関連経験年数と資格、スキル、学歴、保護属性、社員紹介、`performance_score_1y`（ノイズのない適合度の式 + 標準偏差4.5のノイズ + 以前の管理職の偏り：男性 +6、女性 −5、30歳未満 +5、30代 +3、40代 −6、50歳以上 −10、シンガポール人 +6、その他 −2） |
| `job_descriptions.md` | 3職種の説明。必須スキルと歓迎スキルが1つのリストにまとめて書かれている |

データのラベルは5つのロケールすべてでローカライズされていますが、ID と数値はそのままです。応募者のうち113名が、応募した
職種の少なくとも1つで有資格です（R1 39名、R2 57名、R3 26名。うち9名は2職種で有資格）。社員紹介の応募者は15名で、
そのうち6名が有資格です。

## ルール

| ルール | 区分 | 内容 |
|---|---|---|
| `must_have_skills` | 契約上 | 必須スキル2つ、最低限の関連経験（R1 ソフトウェア開発36か月、R2 データ分析24か月、R3 情報セキュリティ24か月。開始月と終了月を含み、`present` は2026年10月まで）、さらに R3 では2026年11月1日に有効な CISSP または Security+ |
| `work_authorization` | 物理的 | R1・R3 にビザスポンサーが必要な人がいないこと。R2 は EOR（雇用代行）を通じたリモート勤務なので対象外 |
| `one_role_per_candidate` | 契約上 | 候補者が載るショートリストは最大1つ |
| `adverse_impact` | 物理的 | 有資格者のうち15名以上の性別、年齢（40歳未満 / 40歳以上）、国籍（シンガポール / その他）の集団は、通過率が最高集団の0.8倍を下回り、**かつ**その集団との両側フィッシャーの正確確率検定で p < 0.05 となる場合に限り不合格 |
| `referral_boost` | 業務慣行（緩和可） | 有資格の紹介候補者は全員ショートリストに載る（会社の慣行） |

品質は、ショートリストの24名それぞれが載っている職種に対して持つ本当の適合度の合計です。本当の適合度は、30 + 最低ライン
を超える関連経験1年ごとの重み（上限あり）+ 重み付きの歓迎スキル + 有効な加点資格 + 学歴（R2）+ ガウスノイズ（標準偏差
3）で、管理職の偏りを除いた過去の評価点と同じ0〜100の尺度です。確認すべき事項は9つで、ショートリストの人数、必須要件、
関連経験、資格の有効期限、就労資格、1職種のみ、過去の採用者の評価点の偏り、アドバースインパクト、社員紹介の慣行です。

## 含まれる状況

- 隠れた事実：上記のすべてのルールに加え、関連経験と資格の有効性の数え方。ワールドの生成器は候補者を最低ラインから
  1か月より大きく離し、資格の有効期限も基準日から離しているため、数え方の細かな取り決めが資格の有無を左右することは
  ありません（レビュー F5）。
- 偏った学習シグナル：過去の採用者の評価点には管理職の偏りが含まれ、過去の採用者では年齢が経験年数から作られているため、
  職務関連の列だけで回帰すると交絡が生じます。要件は属性情報の列をスクリーニング評価点の入力にすることを禁じていますが、
  その偏りを測って取り除くために使うことは認めています。
- 2職種に応募し、どちらにも強い人たち（参照解のショートリストにはそのうち3名）。
- 緩和できる会社の慣行：有資格の紹介候補者6名は各職種の適合度順で下位にいるため、慣行を守ると目的値の約5%を失います。
- 日付のあるイベント、関係者からのプレッシャー、ルールセットはありません（レビュー F3）。

## アドバースインパクトのチェック：較正

有資格者113名に枠が24、集団の規模が約56名の場合、5分の4ルールだけでは2〜3名の差でも不合格になります。このケースは以前、
1名分の許容幅を加えていましたが、保護属性を見ないショートリストでも偶然このチェックに落ちることがありました。現在の
チェックには有意性検定が加わっています（実務的な有意性と統計的な有意性を組み合わせる一般的なやり方です）。5分の4の線を
下回る集団が不合格とされるのは、2 × 2表（この集団と通過率が最も高い集団、通過と不通過）に対する両側のフィッシャーの
正確確率検定で p < 0.05 となる場合だけです。1名分の許容幅は廃止しました。800個の試行ショートリストでは、検定を適用した
あとにこの許容幅が結果を変えたことは一度もありませんでした。

パネル：ワールドごとに、保護属性を見ない最適に近いショートリストを400個、ノイズを加えた評価点に参照解の貪欲な割り当てを
適用して作りました。200個は参照解のスクリーニング評価点から、200個はノイズのない適合度の式から作り、それぞれ候補者・職種
ごとのガウスノイズ（標準偏差0.5、1、2）を加えるか、すべての重みにランダムな係数（標準偏差30%）を掛けました。偏った
学習者：ノイズのない式 + 管理職の偏りの0.5〜1.5倍 + ノイズで評価した200個のショートリスト。ワールドと参照解は変わって
いません。生成器は引き続き、参照解が以前のより厳しいチェックに合格するワールドを選んでいます。

| ワールドシード | 旧チェックの合格（参照解ベース / 式ベース） | 新チェックの合格 | 偏ったショートリストの検出（旧 / 新） |
|---|---|---|---|
| 20261103（公開） | 400個中340個、85.0%（183 / 157） | 400個中400個、100% | 100% / 100% |
| 1 | 400個中341個、85.3%（149 / 192） | 400個中399個、99.8% | 100% / 99.5% |
| 2 | 400個中330個、82.5%（180 / 150） | 400個中399個、99.8% | 100% / 99.5% |
| 3 | 400個中298個、74.5%（139 / 159） | 400個中398個、99.5% | 100% / 100% |

公開シードでは、参照解は最低比率0.727で合格します（その他の国籍 10/56 に対しシンガポール人 14/57、p = 0.49）。保護属性の
効果を評価点に残した過去の採用者の回帰は最低比率0.26で不合格になり（p = 0.001）、女性を飛ばすバリデータの例は0.15で
不合格になります。この検定は、小さな差に対しては旧ルールより検出力が低くなります。歓迎スキルの数による順位付け（最低比率
0.46、p = 0.060）は現在は合格し、管理職の偏りの4分の1は4つのワールドのどれでも検出されません。

## 参照解とベースライン（シード 20261103）

**参照解**は、有資格の紹介候補者をそれぞれ最も評価点の高い職種に入れたうえで、単純なスクリーニング評価点（関連経験年数 +
歓迎スキル1つにつき1.5 + 有効な加点資格に2）で（候補者、職種）の組を貪欲に割り当てます。**ベースライン**は、エンジニアが
いない場合に顧客が現在行っているやり方です。同じ必須要件のフィルター、社員紹介の慣行、1職種のルールを適用したあと、関連
経験年数の多い順に選び、それ以外は何も見ません。

正規化した品質は q = (目的値 − 1226.29) / (1254.49 − 1226.29) です。方針の既定の上限1.5には、目的値1268.59（参照解の
1.011）で達します。

| ショートリスト | 目的値 | 参照解との比 | q | 有効 |
|---|---|---|---|---|
| ベースライン：関連経験年数のみ | 1226.29 | 0.978 | 0 | はい |
| 参照解 | 1254.49 | 1.000 | 1 | はい |
| ランダムな評価点、同じ貪欲な割り当て（211個の抽出中、有効200個） | — | 0.851–0.995、平均0.934 | 0未満 | はい |
| 総経験年数による順位付け（必須要件は維持） | 1203.18 | 0.959 | 0未満 | はい |
| 歓迎スキルの数による順位付け | 1285.52 | 1.025 | 2.10 | はい |
| 過去の採用者の回帰、経験年数に上限、職務の列のみ | 1314.84 | 1.048 | 3.14 | はい |
| 同じ回帰に保護属性を統制変数として追加（評価点の計算では除外） | 1328.65 | 1.059 | 3.63 | はい |
| 回帰、経験年数は線形、職務の列のみ | 1279.46 | 1.020 | — | いいえ：アドバースインパクト（p = 0.037） |
| 保護属性の項を評価点に残した回帰 | 1260.09 | 1.004 | — | いいえ：アドバースインパクト（p = 0.001） |
| ノイズのない適合度の式 | 1315.86 | 1.049 | 3.18 | はい |
| 適合度オラクル（ノイズを含む本当の適合度） | 1343.64 | 1.071 | 4.16 | はい |
| 社員紹介の慣行を外した参照解 | 1316.22 | 1.049 | 3.19 | `referral_boost` を緩和した場合のみ |

ワールドシード1、2、3では、ベースラインは参照解の0.951、0.949、0.957です（目的値 1170.98 対 1231.73、1116.54 対 1176.82、
1140.42 対 1192.18）。ベースラインはアドバースインパクトのチェックをまったく考慮しないため、生成器はベースラインも有効で
あることを求めています。この条件がなければ、ワールドシード23でベースラインがチェックに落ちていました（p = 0.037）。
ワールドシード1〜40では、ベースラインは参照解の0.913–0.996（中央値0.961）で、差が1%以内のところでは正規化した尺度が
非常に急になります。有能な学習者はすべて上限を超えるため、品質の項目はベースラインと参照解レベルのエージェントを区別
できても、優れた学習者とオラクルは区別できません（レビュー F1）。

## 補足

- 合成データです。候補者、職歴、スキル、資格、評価点、偏りの大きさは生成されたもので、適合度の重みは設計上の選択です。
  5分の4ルールは米国の慣行（Uniform Guidelines on Employee Selection Procedures、29 CFR 1607.4D。この指針は、少数に
  基づく統計的に有意でない差はアドバースインパクトに当たらない場合があるとも述べています）に従っており、40歳以上という
  年齢の区切りも同様です（米国の Age Discrimination in Employment Act）。要件はこのチェックを法的要件と呼んでいますが、
  ケースの舞台はシンガポールで、シンガポールでこのような統計的検定が法律で定められているとは知られていません（レビュー
  F8）。
- このページの数値はすべて `case.py`（`_solve`、`check`、`_fit_value`）から得たものです。パネルと回帰は分析スクリプトに
  よるもので、ケースの一部ではありません。
- `validate-case` は、5つのロケールでの決定性、品質1の参照解、有効でより悪いベースライン、ルールごとに1つの違反例、
  ワールドシード1〜3を確認します。
