# 채용 중인 직무

## R1 백엔드 엔지니어 (플랫폼팀)
- 근무 형태: 하이브리드, 주 3일 이상 사무실 출근
- 담당 업무: 결제 플랫폼의 백엔드 서비스와 내부 API를 설계·운영하고, 확장 작업과 온콜 당번에 참여합니다.
- 이런 분을 찾습니다: Python, SQL, Kubernetes, AWS, Go, Docker; 백엔드 개발 경력 수년; 클라우드 배포 경험이 있으면 우대합니다.

## R2 데이터 분석가 (그로스팀)
- 근무 형태: 전면 원격 근무, EOR(고용대행) 파트너를 통한 계약 가능
- 담당 업무: 비즈니스 지표 체계를 만들고, 실험을 설계·해석하며, 제품·마케팅팀을 데이터로 지원합니다.
- 이런 분을 찾습니다: SQL, 통계학, A/B 테스트, Python, Tableau, Power BI, Excel; 데이터 분석 실무 경력; 석사 이상이면 우대합니다.

## R3 보안 분석가 (보안관제센터)
- 근무 형태: 상주 근무, 고객사 데이터센터 출입 필요
- 담당 업무: 보안 경보를 모니터링하고 침해사고를 처리하며, 네트워크 경계와 클라우드 환경의 보안 정책을 관리합니다.
- 이런 분을 찾습니다: 네트워크 보안, SIEM, 침해사고 대응, 클라우드 보안, Linux, Python; 정보보안 분야 경력; 공인 보안 자격증 보유.
