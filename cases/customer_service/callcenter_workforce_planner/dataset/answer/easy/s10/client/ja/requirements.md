# 多言語サポートセンターの週間シフト表

## 背景

来週（11月9日月曜日〜15日日曜日）のサポートチームのシフト表を作っていただけますか。対応しているどの言語でもお客様をお待たせしないよう、電話に出られる人数を十分に確保したいです。担当者一覧と入電の見込みを添付します。

## 成果物

JSONファイル1つ、`roster.json`：`{"assignments": [{"agent": "A01", "day": "2026-11-09", "shift": "S0800", "language": "ko"}, ...]}`。担当者が勤務するシフト1回につき1件です。`agent` と `shift` はデータのとおりに、`day` はYYYY-MM-DD形式で、`language` はコード `ko`（韓国語）、`ja`（日本語）、`en`（英語）、`zh`（中国語）、`es`（スペイン語）のいずれかで記載します。

## データの説明

- `オペレーター一覧.xlsx` の `担当者` シートには、担当者ごとの `雇用形態`（正社員 / パート）と `新人` があります。`対応言語` シートは、担当者が電話対応できる言語を担当者・言語ごとに1行で記載したものです。配置できるのはこの30名だけです。
- `入電予測.csv` は入電件数ではなく、すでに人数に換算した値です。`必要人数` は `開始時刻`（08:00〜21:30。受付時間は08:00〜22:00）から始まる30分枠ごとに、言語別に必要な担当者数です。充足は30分枠ごとに確認し、担当者はシフト時間内のすべての枠に数えられます（S0800なら08:00〜15:30の枠）。
- 担当者は1回のシフト中、`language` に記載した1言語だけで対応します。その言語は本人の対応言語でなければなりません。バイリンガルの担当者でも、同時に2言語分として数えることはできません。
- `シフト.csv` のとおり、正社員は8時間シフト（S...）のみ、パートは4時間シフト（P...）のみ勤務できます。
- 正社員は週5回まで、パートは週3回までです。
- 担当者のシフトは1日1回までです。
- `休暇一覧.csv` の日付は日/月/年の順です（10/11/2026は11月10日）。`開始日` と `終了日` はどちらも含みます。`承認状況 = 承認済み` のものだけが休暇で、`却下` の申請は通常どおり勤務できるという意味です。
- `人件費.csv` に雇用形態別の時給があります。
- `リーダーからの連絡.txt`：はい、そこに書かれている担当者は月曜日に復帰します。ほかの担当者と同じように配置してください。

**今回の範囲**

- どの日も予測ファイルのとおりに計画してください。今回は日ごとの調整はしません。
- どのシフトも通常の時給で人件費を計算してください。今回は時間外手当を給与担当が別に精算します。
- 休息時間：1人1日1シフトだけ守ってください。休息時間は現場の管理者があとで確認します。
- 新人もほかの担当者と同じように配置してかまいません。当日、現場の管理者が新人ではない担当者と組ませます。

## 評価の概要

**必須の制約**（1つでも破るとシフト表は無効）：

- 担当者は自分の対応言語でのみ対応する。
- 正社員は8時間シフトのみ、パートは4時間シフトのみ。
- 週のシフト回数は正社員5回まで、パート3回まで。
- 担当者のシフトは1日1回まで。
- 承認済みの休暇中には誰も配置しない。

**品質**：枠・言語ごとに不足する担当者1名につき40（`必要人数` から、その枠でその言語に配置された人数を引いた値が正の場合）に、全シフトの人件費（時間 × 時給）を加えた値。40は人件費と同じ単位で、担当者が1名30分不足したときの放棄呼・折り返し対応・サービスレベル未達による損失を当社が見積もった額です。必要人数を超える配置は人件費以外の減点はありません。低いほど良い。
