# 多语种客服中心周排班

## 业务背景

麻烦帮客服团队排一下下周（11月9日周一到15日周日）的班表吧。我们支持的每个语种都要有足够的人接电话，别让客户等太久。员工名单和预计话务量在附件里。

## 产物形式

交一份 JSON 文件 `roster.json`：`{"assignments": [{"agent": "A01", "day": "2026-11-09", "shift": "S0800", "language": "ko"}, ...]}`。每位坐席每上一个班记一条。`agent` 和 `shift` 与数据中完全一致，`day` 用 YYYY-MM-DD 格式，`language` 填代码 `ko`（韩语）、`ja`（日语）、`en`（英语）、`zh`（中文）或 `es`（西班牙语）。

## 数据说明

- `人员名单.xlsx` 的 `员工` 工作表列出每位坐席的 `用工类型`（全职 / 兼职）和 `新员工`；`语言技能` 工作表每行是一位坐席能接听的一个语种。可排班的只有这 30 个人。
- `话务量预测.csv` 给的已经是人数而不是来电量：`所需坐席数` 是从 `时段开始`（08:00 到 21:30，热线开放时间 08:00-22:00）起的半小时时段内，每个语种需要的坐席人数。按半小时时段逐个检查覆盖情况，坐席在其班次内的每个时段都算在岗（S0800 覆盖 08:00 到 15:30 这些时段）。
- 一个班次内坐席只接一个语种，即 `language` 里填的那个，而且必须是其语言技能之一。会两种语言的坐席同一时间也只算一个语种，不能同时算两个。
- 按 `班次.csv`：全职只能上 8 小时班（S...），兼职只能上 4 小时班（P...）。
- 全职每周最多上 5 个班，兼职每周最多 3 个班。
- 每位坐席每天最多上一个班。
- `请假记录.csv` 的日期是“日/月/年”格式（10/11/2026 是 11月10日），`开始日期` 和 `结束日期` 都包含在内。只有 `审批状态 = 已批准` 的才算请假；`已驳回` 的申请表示该坐席正常上班。
- `人工成本.csv` 给出各用工类型的时薪。
- `组长留言.txt`：对，留言里说的那位坐席周一就回来上班，和其他人一样排班即可。

**本轮范围**

- 每天都按预测文件原样安排，本轮不做按天的调整。
- 每个班都按普通时薪计算成本，加班费本轮由薪资部门另行结算。
- 休息时间：每人每天只排一个班就行，休息时间由现场主管事后核对。
- 新员工可以和其他人一样排班，当天由现场主管安排一位非新员工带着。

## 评分方式

**硬性约束**（任意一条不满足，班表即无效）：

- 坐席只接自己会的语种。
- 全职只上 8 小时班，兼职只上 4 小时班。
- 每周班次数：全职最多 5 个，兼职最多 3 个。
- 每位坐席每天最多一个班。
- 已批准的请假日不排班。

**质量**：每个时段、每个语种每缺一名坐席记 15（`所需坐席数`，减去该时段该语种已排的人数，为正时计入），再加上所有班次的人工成本（时长 × 时薪）。15 与时薪是同一单位，是我们估算的每缺一名坐席半小时所造成的损失（客户放弃来电、回拨处理、服务水平不达标）。超出需求的人手除人工成本外不另扣分。数值越低越好。
